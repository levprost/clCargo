Оформи структуру первого этапа по references/desktop-layout-reference.png и правилам ниже. Стили ограничь hero-компонентом и используй действующую архитектуру CSS/SCSS. Не переоформляй шапку, модальное окно и остальные секции.

## Типографика и сетка

Предпочтительная гарнитура Manrope, запасная Inter, затем system-ui/sans-serif. Если в теме уже используется одна из этих гарнитур, используй её без подключения второго похожего семейства. Заголовок 800, UI 600–700, описание 400–500.

Контейнер до 1280px, по центру. Боковые отступы на узких экранах 16px, на широких 24–40px. На десктопе две колонки приблизительно 56%/44% от пространства, оставшегося после gap 40–48px; не складывай проценты с gap так, чтобы ширина превысила контейнер. У колонок min-width:0.

Ориентиры:
- H1: 48–64px на широком экране, 30–36px на телефоне; line-height 1.08–1.15. Выделенную часть «під ключ»/«под ключ» можно выводить отдельной строкой. Не фиксируй одинаковые ручные переносы для всех ширин и языков.
- Lead: 20–22px на десктопе, 17–18px на телефоне; line-height 1.5.
- Подробный абзац: 16–18px, line-height 1.6.
- Девиз: 22–24px на десктопе, 18–20px на телефоне; пояснение 15–16px.
- Кнопки: минимум 48px по высоте; текст 15–16px; радиус 12–14px; padding 14–16px по вертикали и 20–24px по горизонтали. Разреши рост высоты при переносе подписи.
- Бейдж опыта: 13–14px, тонкий контур, золотистая точка; на телефоне разрешён перенос текста.
- Чипы направлений: 14–16px, радиус 10–12px, gap 8–12px. На телефоне сетка 2×2, при нехватке места одна колонка.
- Фото и баннер: радиус 16–20px.

Блок девиза оформлен золотистой вертикальной линией и иконкой щита. Преимущества отделены сверху тонкой линией: на десктопе четыре колонки, на мобильном две, на самых узких при необходимости одна. Без тяжёлых теней и отдельных массивных карточек. Иконки и текст не накладываются.

## Готовые иконки

Используй локальные SVG из assets/icons; не заменяй их эмодзи:
- shield-check.svg — девиз и ответственность за сохранность;
- package.svg — сборные партии;
- credit-card.svg — оплата поставщикам;
- warehouse.svg — зарубежные склады;
- calculator.svg — расчёт доставки;
- phone.svg — звонок менеджеру.

SVG рассчитаны на viewBox 0 0 24 24, stroke currentColor, толщину 1.8, скруглённые окончания. Для изменения цвета можно использовать проверенный inline SVG из этих локальных файлов; при обычном img currentColor не наследуется от страницы. В преимуществах размер 28–36px, в кнопках 20–22px. Иконки золотистые, на золотой кнопке — тёмно-синие.

Флаги находятся в assets/flags: tr.svg, cn.svg, in.svg, eu.svg, pl.svg. Показывай их в одинаковых прямоугольниках примерно 24×16px, для Европы два рядом. При наличии текстового названия страны флаг декоративный: alt пустой. Не полагайся на системные emoji-флаги.

Сохрани естественную высоту блоков: никакого line-clamp, обрезания текста, фиксированной высоты всего hero или принудительного 100vh. Фон приложения остаётся тёмно-синим; синие цвета внутри баннера не меняют палитру всех кнопок.
